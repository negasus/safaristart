# SafariStart — стартовая страница Safari с группами ярлыков

## Контекст

Хочется своя стартовая страница (новая вкладка) в Safari, где ярлыки сайтов удобно разложены по группам: группы-карточки в сетке, которые можно перетаскивать, менять ширину, принудительно переносить на новую строку и отделять разделителями. Репозиторий пустой (`/Users/negasus/code/negasus/safaristart`, ветка `master`, без коммитов). Есть Xcode 27 с `safari-web-extension-converter` и Node 22.

Решения, принятые в обсуждении:
- ярлыки добавляются вручную через UI страницы;
- раскладка: группы-карточки в сетке, авто-перенос + ширина группы (S/M/L/на всю строку) + принудительный разрыв строки / разделитель с подписью;
- ярлык — чип «фавиконка + название»;
- хранение только локально (без синка и без импорта/экспорта);
- ванильный JS + CSS, ES-модули, без сборки и зависимостей;
- иконки через сервис Google favicons, если не загрузилась — цветной кружок с буквой;
- в v1: цвет группы, сворачивание групп, быстрый поиск/фильтр.

## Подход

Safari Web Extension (Manifest V3), которое подменяет новую вкладку через `chrome_url_overrides.newtab`. Safari умеет выбирать страницу расширения в «Настройки → Основные → Новые вкладки/окна открываются с». Xcode-проект-обёртка (macOS app + extension) генерируется `safari-web-extension-converter` и **ссылается** на папку `extension/` (без `--copy-resources`), так что веб-код правится в одном месте.

## Структура

```
extension/
  manifest.json          MV3: name, version, chrome_url_overrides.newtab, permissions ["storage"], icons
  newtab.html            разметка: тулбар (поиск, «+ группа», «+ разрыв», переключатель «Правка»), #board, <dialog>
  css/newtab.css         токены цветов, светлая/тёмная тема (prefers-color-scheme), сетка, чипы, карточки
  js/main.js             загрузка состояния, подписка на изменения, связка модулей
  js/model.js            ЧИСТЫЕ функции над состоянием (без DOM) — тестируются в node
  js/store.js            load/save через browser.storage.local; фолбэк на localStorage, если `browser` нет (для разработки в обычном браузере)
  js/render.js           состояние → DOM
  js/dnd.js              drag&drop на нативном HTML5 DnD
  js/editor.js           диалоги редактирования ярлыка/группы/разрыва
  js/search.js           фильтр и клавиатурная навигация
  js/favicon.js          URL иконки + фолбэк-буква с цветом из хеша домена
  icons/                 иконки расширения (16/32/48/128)
tests/model.test.js      node --test
SafariStart/             Xcode-проект (генерируется конвертером)
docs/superpowers/specs/2026-09-18-safaristart-design.md   этот дизайн в виде спеки
```

## Модель данных (`browser.storage.local`, ключ `board`)

```json
{
  "version": 1,
  "items": [
    { "type": "group", "id": "g1", "title": "Работа", "color": "blue",
      "width": "m", "collapsed": false,
      "links": [ { "id": "l1", "title": "Gmail", "url": "https://mail.google.com" } ] },
    { "type": "break", "id": "b1", "label": "Личное" }
  ]
}
```
- `items` — упорядоченный плоский список групп и разрывов; порядок = порядок на экране.
- `width`: `s` | `m` | `l` | `full`; `color` — ключ из фиксированной палитры (~8 цветов, каждый со светлым и тёмным вариантом).
- `break` с пустым `label` — просто перенос строки, с непустым — разделитель с подписью.
- `id` через `crypto.randomUUID()`.
- При первом запуске — демо-доска с одной группой.

`model.js` экспортирует: `createGroup`, `updateGroup`, `removeItem`, `addBreak`, `addLink`, `updateLink`, `removeLink`, `moveItem(state, fromIdx, toIdx)`, `moveLink(state, linkId, toGroupId, toIndex)`, `toggleCollapsed`, `filterLinks(state, query)`, `normalizeUrl(input)` (добавляет `https://`, если схемы нет), `migrate(raw)` (проверяет `version`, битые данные → пустая доска). Все функции возвращают новое состояние и не мутируют исходное.

## Раскладка

- `#board` — CSS Grid на 12 колонок, `grid-auto-flow: row`. Ширина группы: `s`=3, `m`=4, `l`=6, `full`=12 колонок. `break` — `grid-column: 1 / -1`, это и даёт принудительный перенос.
- Адаптивность через container queries: на узком окне S/M растягиваются до 6, потом до 12 колонок.
- Внутри группы чипы идут через `flex-wrap`. Чип: иконка 16px + название с `text-overflow: ellipsis`.
- Свёрнутая группа показывает только заголовок и число ярлыков.

## Взаимодействие

- **Режим просмотра** (по умолчанию): чипы — обычные `<a href>`, клик открывает сайт в текущей вкладке, Cmd+клик — в новой (штатное поведение Safari). Клик по заголовку группы сворачивает/разворачивает её.
- **Режим правки** (переключатель в тулбаре, состояние в `localStorage`): включается `draggable`, появляются кнопки ✎/× у чипов и групп, «+ ярлык» в каждой группе, выбор ширины и цвета в заголовке группы.
- **Drag&drop** (`dnd.js`): чип можно двигать внутри группы и между группами (индикатор места вставки), группу или разрыв — по доске. На drop вызывается `moveLink`/`moveItem`, потом save и render.
- **Диалоги** (`<dialog>`): ярлык (название, URL; если название пустое — берётся hostname), группа (название, цвет, ширина), разрыв (подпись).
- **Поиск**: поле в тулбаре; `/` или любая печатная клавиша, когда фокус на странице, переводят фокус в поле. Фильтр по названию и URL скрывает несовпавшие чипы и пустые группы (свёрнутые группы на время поиска раскрываются). ↑/↓ двигают выделение, Enter открывает выделенный ярлык, Esc очищает поиск. Ограничение: у только что открытой вкладки Safari ставит фокус в адресную строку, поэтому сначала нужен клик по странице или Tab.
- **Иконки**: `https://www.google.com/s2/favicons?domain=<host>&sz=64`, `loading="lazy"`; `onerror` — кружок с первой буквой, цвет из хеша домена.
- **Синхронизация вкладок**: `browser.storage.onChanged` перерисовывает другие открытые вкладки новой страницы.

## Шаги реализации

1. Записать спеку в `docs/superpowers/specs/2026-09-18-safaristart-design.md`, `.gitignore` (xcuserdata, DerivedData, .DS_Store), закоммитить.
2. Написать `model.js` и `tests/model.test.js` по TDD: сначала тесты для move/add/remove/filter/normalizeUrl/migrate.
3. `manifest.json`, `newtab.html`, `store.js`, `render.js`, `main.js`: статическая отрисовка доски.
4. `editor.js`, затем режим правки, `dnd.js`.
5. `search.js`, `favicon.js`, сворачивание, цвета.
6. CSS: темы, сетка, адаптивность, аккуратные состояния hover/focus/drag (через скилл frontend-design).
7. Сгенерировать Xcode-проект:
   `xcrun safari-web-extension-converter extension --project-location . --app-name SafariStart --bundle-identifier com.negasus.safaristart --macos-only --no-open --no-prompt`
   Потом выставить signing на Personal Team. Без подписи Safari потребует «Разработка → Разрешить неподписанные расширения» после каждого перезапуска.
8. README: как собрать, включить расширение и выбрать его для новых вкладок.

- `node --test tests/` — модель.
- Разработка без Safari: `python3 -m http.server` в `extension/`, открыть `newtab.html` через Playwright (сработает фолбэк store на localStorage). Проверить добавление и редактирование, DnD чипов между группами, DnD групп, разрыв и разделитель, ширины, сворачивание, поиск с Enter/стрелками, фолбэк иконки, тёмную тему, узкое окно. Сделать скриншоты.
- `xcodebuild -project SafariStart/SafariStart.xcodeproj -scheme SafariStart build` — сборка проходит.
- Вручную в Safari: запустить приложение, включить расширение в настройках, выбрать его для новых вкладок, открыть новую вкладку. Данные должны сохраняться после перезапуска Safari, а правки в одной вкладке — появляться в другой.
